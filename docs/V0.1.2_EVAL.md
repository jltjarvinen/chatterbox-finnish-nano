# v0.1.2 automatic evaluation

The release evaluation is automatic and does not replace human listening or MOS.

## Finnish intelligibility proxy

The fixed set contains 100 sentences:

- 20 ordinary
- 20 home automation
- 20 Finnish phonetic stress cases
- 20 numeric
- 20 longer conversational sentences

Faster-Whisper `large-v3-turbo` was used as the ASR scorer.

| Model | WER | CER | normalized exact |
| --- | ---: | ---: | ---: |
| Stock Nano FP16 | 97.94% | 34.45% | 0% |
| v0.1.2 BF16 | 10.60% | 1.65% | 54% |
| v0.1.2 FP16 | 10.60% | 1.65% | 54% |

BF16 and FP16 produced the same normalized ASR hypothesis on all 100 sentences.

Category WER for v0.1.2:

| Category | WER |
| --- | ---: |
| ordinary | 6.72% |
| long | 7.35% |
| numbers | 10.78% |
| home | 13.27% |
| phonetic | 20.00% |

## Slim package equivalence

Full and slim v0.1.2 differ by exactly one file:

```text
s3gen.safetensors
```

The pinned Nano runtime never requested it.

Three deterministic equivalence prompts produced identical T3 speech tokens and
byte-identical final waveforms.
