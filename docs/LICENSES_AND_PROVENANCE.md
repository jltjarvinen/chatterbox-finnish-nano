# Licenses and provenance

## Repository source code

The source code in this repository is distributed under the MIT license in `LICENSE`.

## Base model

The release builder downloads a pinned `ResembleAI/chatterbox-nano` snapshot and replaces only its Nano T3 checkpoint with the selected Finnish-adapted T3 weights. The builder intentionally retains the base model's other assets, including `conds.pt` used by the built-in zero-shot path.

The upstream Chatterbox Nano Hugging Face model card currently identifies the model as MIT licensed, and the pinned Chatterbox source revision is distributed under the upstream MIT license. The release keeps the upstream license notice and records the exact base/runtime revisions. Training-data redistribution rights are separate from the generated model artifact.

## Training sources

The final adaptation used cached synthetic Finnish S3 targets generated by Chatterbox Multilingual V2 and a cleaned real-audio Rautatie corpus for a very small final polish. The public runtime repository does **not** include training audio, Project Gutenberg source text dumps, synthetic S3 target caches or private bucket contents.

Keep detailed source manifests and any required attribution alongside the private research/training archive. Re-check the exact terms of each training source before distributing training data itself.
